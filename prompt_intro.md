3. BOOTSTRAP
==================================================

BẮT BUỘC sử dụng Bootstrap.

Sử dụng:

Bootstrap 5.x

Có thể sử dụng:

- container
- container-fluid
- row
- col
- g-*
- d-flex
- align-items-*
- justify-content-*
- responsive utilities
- navbar
- buttons
- cards nếu phù hợp
- accordion nếu phù hợp

Bootstrap dùng để xử lý:

- Grid
- Responsive
- Spacing
- Layout
- Navbar
- Utility classes
- Mobile responsive

Tuy nhiên:

KHÔNG để giao diện nhìn giống Bootstrap mặc định.

Hãy custom CSS riêng để tạo:

- Typography
- Colors
- Borders
- Buttons
- Cards
- Images
- Hover effects
- Editorial layout

Ưu tiên:

Bootstrap + Custom CSS

Không sử dụng Tailwind.

Không sử dụng React.

Không sử dụng Laravel.

Project là:

PHP thuần + MVC + MySQL/MariaDB + Bootstrap 5.

==================================================
17. RESPONSIVE
==================================================

Sử dụng Bootstrap responsive breakpoint.

Desktop:
- layout rộng
- nhiều whitespace
- hình ảnh lớn.

Tablet:
- giảm spacing
- thay đổi grid.

Mobile:
- các section chuyển thành 1 column
- hình ảnh phía trên/dưới tùy section
- typography giảm kích thước
- navbar collapse
- không horizontal overflow.

Phải kiểm tra:

375px
768px
992px
1200px
1440px
